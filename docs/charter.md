# SandboxHub 项目章程（Charter）

## 1. 项目名称与定位
- 名称：**SandboxHub**
- 定位：公司内部 AI 沙箱平台（Internal PaaS），面向**开发者自助**与**运维/租户管理**
- 底座：OpenSandbox（Apache-2.0，零改动核心）

## 2. 目标
- 提供统一、隔离、可审计的 AI 代码执行环境
- 开发者可自助创建/使用/销毁沙箱（终端、命令、文件、端点、指标）
- 运维/租户管理员可管理租户、配额、模板、策略、审计与观测

## 3. 范围
**范围内**：多租户逻辑隔离、SSO、沙箱生命周期、终端/命令/文件/端点/指标、出网策略、模板、快照、审计、管理端。
**范围外**：对外商业化计费、货币结算、跨云联邦、K8s 原生 Pool（列为后续可选）。

## 4. 干系人
| 角色 | 关注点 |
|---|---|
| 平台管理员 | 稳定性、隔离、审计、容量 |
| 租户管理员 | 成员、配额、用量 |
| 开发者 | 易用性、速度、终端/文件体验 |
| 安全/审计 | 越权、密钥、可追溯 |

## 5. 成功指标
- 沙箱创建到可用 P95 < 30s（预热后）
- 开发者自助开通 < 1 天
- 审计事件 100% 落库可查
- 关键旅程 E2E 通过率 100%
- 沙箱可用率 ≥ 99.5%（单 VM 基线）

## 6. 里程碑
M0 立项/文档 → M1 基础设施 → M2 BFF 基础 → M3 核心 API → M4 Web 骨架 → M5 创建/详情/终端 → M6 文件/指标/策略 → M7 模板/快照/Key → M8 管理端 → M9 测试/部署/验收。
