Enterprise Sandbox Platform · Design Spec

从开发者工作台到企业治理台
一套可扩展的 UI 体系

本规范定义 SandboxHub 在企业级演进中的界面增量：四组信息架构、设计系统 v2（暗/亮 + 中英）、关键页面线框、组件清单与交互规范。演进而非重写，复用现有暗色体系与 Ant Design 5。

1

设计原则

Design principles

五条原则指导所有增量设计，确保演进一致、不返工。

角色驱动

开发者看「工作台」，运维/管理员看「治理台」；菜单、页面、操作按角色渲染（前端隐藏 + 后端二次校验）。

实时优先

状态/事件/指标用 SSE/WebSocket 推送，替换 5s 轮询；操作结果即时反馈（乐观更新 + 失败回滚）。

密度可控

列表用强大表格，详情用 Drawer 保留上下文；复杂表单分步，高级项折叠。

一致五态

加载 / 空 / 错 / 无权限 / 禁用 五态统一组件与文案。

演进而非重写

保留暗色 token 与 AntD 组件，扩展为双主题 + i18n；旧路由重定向兼容。

可观测即界面

用量、配额、审计、健康直接进入界面，成为一等公民而非隐藏设置。

组件清单

packages/ui · 新增与增强

StatusBadge

统一状态色/文案：Running/Paused/Pending/Failed/Terminated；含脉冲动效表示过渡态。

QuotaBar

配额进度条，支持正常/预警/超额三态与内联数值。

MetricChart / MiniSpark

ECharts 封装；列表内嵌迷你趋势线，详情页多序列历史曲线。

PolicyEditor

出网规则结构化编辑（defaultAction + allow/deny + FQDN/CIDR/通配），冲突提示。

TerminalPane

xterm 封装：多标签、搜索、复制粘贴、主题、会话录制开关、重连回放。

FileTree + CodeEditor

懒加载文件树 + Monaco（语法高亮、多文件标签、拖拽上传进度）。

ApprovalTimeline

申请/审批状态时间线（提交→审批→通过/驳回）。

LogViewer

虚拟滚动 + 关键字高亮 + 时间范围 + 级别筛选（BFF/沙箱/审计）。

AuditTable + DetailDrawer

审计检索（时间/动作/租户/结果）+ 详情抽屉（参数脱敏、diff）。

CommandPalette

⌘K 全局导航与操作（跳转、创建、执行常用命令）。

EmptyState / ErrorState

统一空态/错误/无权限插图与引导动作。

PermissionGate <Can>

按权限渲染/禁用元素；配合路由守卫。

交互规范

实时 / 批量 / 审批 / 抽屉 / 乐观更新 / 五态

实时状态

SSE 推送沙箱状态、指标、事件；列表 Badge 与详情状态条即时更新；顶部活动流滚动。断线自动重连并提示。

批量操作

列表多选 → 底部操作条；二次确认；结果汇总（成功/失败计数）；失败项可重试。

审批流

申请 → 待审 → 通过/驳回；状态时间线；通知（铃铛/邮件/IM）；审批人可见上下文（用量/历史）。

抽屉详情

列表点开用 Drawer 展示，保留筛选与滚动位置；支持 URL 深链（?detail=id）。

乐观更新

生命周期操作即时反馈（按钮 loading + 状态预测），失败回滚并 Toast 错误码。

五态

加载（Skeleton）/ 空（引导创建）/ 错（可重试）/ 无权限（申请入口）/ 禁用（原因 Tooltip）。

8

响应式与无障碍

Responsive & A11y

响应式

断点：≥1100 双栏；≤1100 侧栏收起、栅格降列；≤720 单列、表格横向滚动或卡片化、终端适配移动端软键盘与字号。

关键操作（看状态、执行命令、销毁）在移动端可用。

无障碍

语义 HTML、键盘全可达、焦点管理、对比度达标、ARIA 地标（<main>/<nav>）、屏幕阅读器文案、减少动效（prefers-reduced-motion）。

沿用课程站点的 a11y 校验标准（语义/键盘/对比度）。
