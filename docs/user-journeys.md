# SandboxHub 用户旅程（User Journeys）

> 每条旅程含：角色 / 目标 / 前置 / 主流程 / 成功标准 / 边界异常 / 验收用例 ID。
> **验收用例 ID 与 Playwright E2E 用例一一对应，是"开发完成"的判定依据。**

## 角色
- **P** 平台管理员 · **T** 租户管理员 · **D** 开发者 · **A** 审计/只读

---

## 开发者旅程（D）

### J-D1 首次登录
- **目标**：SSO 登录后进入工作台并看到自己的租户
- **前置**：Keycloak 已有账号
- **主流程**：访问 `http://<vm>:8081` → 跳转 Keycloak → 登录 → 回调 → 概览显示所属租户与沙箱统计
- **成功标准**：`/me` 返回用户与角色；顶部显示租户切换器
- **边界**：无任何租户 → 显示"等待加入租户"引导页
- **验收**：`E2E-D1`

### J-D2 从模板创建沙箱
- **目标**：快速获得可用隔离环境
- **前置**：developer 角色；租户配额充足
- **主流程**：沙箱→创建 → 选模板「Python 3.12」→ 向导带出镜像/entrypoint/资源默认 → 设超时与出网策略 → 提交 → 进度 Pending→Running → 跳详情
- **成功标准**：状态 Running；详情显示 sandbox_id 与端点；审计有 create 记录
- **边界**：镜像拉取慢→进度与超时兜底；配额不足→明确报错；无权限→按钮禁用
- **验收**：`E2E-D2`

### J-D3 终端与命令执行
- **目标**：在浏览器内交互式执行
- **主流程**：详情·终端 → 打开 PTY → 执行 `python --version` → 详情·命令 → 跑命令看 SSE 流式输出与退出码
- **成功标准**：终端可输入/输出/resize；命令流式输出完整
- **边界**：终端断线→可重连回放；只读角色→viewer 模式
- **验收**：`E2E-D3`

### J-D4 文件收发与编辑
- **目标**：在沙箱与本地间交换文件
- **主流程**：文件 Tab → 上传本地文件 → 列表可见 → Monaco 打开编辑保存 → 下载校验内容一致
- **成功标准**：上传/下载/编辑/删除/移动均生效；大文件流式
- **边界**：无权限目录→拒绝提示；二进制文件→只读/下载
- **验收**：`E2E-D4`

### J-D5 访问沙箱内服务端点
- **目标**：访问沙箱内起的服务
- **主流程**：起 HTTP 服务（`python -m http.server 8000`）→ 详情·端点 → 经 BFF 代理打开 → 返回内容
- **成功标准**：代理可访问且带鉴权；未开放端口→明确提示
- **验收**：`E2E-D5`

### J-D6 监控资源与状态
- **目标**：观察沙箱健康
- **主流程**：详情·指标 → CPU/内存/进程实时曲线；事件 Tab → 状态迁移时间线
- **成功标准**：指标持续刷新；事件与操作对应
- **验收**：`E2E-D6`

### J-D7 配置出网策略
- **目标**：最小化出网
- **主流程**：详情·网络 → defaultAction=deny → 加 allow `example.com` → 保存 → 沙箱内验证可达/不可达
- **成功标准**：策略生效；`gvisor + networkPolicy` 组合被禁用并说明（C5）
- **验收**：`E2E-D7`

### J-D8 生命周期操作
- **目标**：暂停/恢复/续期/销毁
- **主流程**：pause → Paused → resume → Running → renew 延长到期 → kill 销毁并回列表
- **成功标准**：状态与到期时间正确；审计完整
- **边界**：对已失败沙箱 resume → 明确报错
- **验收**：`E2E-D8`

### J-D9 快照
- **目标**：保存沙箱状态
- **主流程**：创建快照 → 列表可见 →（Docker 下标注恢复能力限制）
- **成功标准**：快照记录与状态可查；能力限制如实提示
- **验收**：`E2E-D9`

### J-D10 个人 API Key 与 CLI
- **目标**：脚本化访问
- **主流程**：我的 Key → 创建 → 复制 → 用官方 SDK/CLI 指向 BFF 创建沙箱
- **成功标准**：Key 生效、可吊销、可查看最近使用
- **验收**：`E2E-D10`

### J-D11 异常与权限
- **目标**：错误可理解
- **主流程**：触发创建失败/超时/越权访问他人沙箱
- **成功标准**：四态齐全（加载/空/错/无权限），错误可读可重试
- **验收**：`E2E-D11`
